# 🎭 Коллекционер — интернет-магазин коллекционных товаров

Клиентская часть интернет-магазина коллекционных товаров (винил, фигурки, монеты), разработанная на React + Vite. Данные получаются из публичного API DummyJSON.

## Стек
- React 18
- React Router 6
- Vite 5
- Context API (корзина, авторизация, UI)
- CSS3 (mobile-first)

## Запуск

```bash
npm install
npm run dev
