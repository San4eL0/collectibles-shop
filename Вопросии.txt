Слайд 1 — Титульный «Уважаемые члены комиссии! Представляю вашему вниманию курсовую работу на тему „Интернет-магазин коллекционных товаров“. Работу выполнил студент группы 454 Шило Александр».

Слайд 2 — Цель и задачи «Целью работы стала разработка клиентской части интернет-магазина коллекционных товаров с уникальным интерактивным дизайном и высоким пользовательским опытом. Для достижения цели были поставлены пять задач: анализ предметной области, выбор технологического стека, проектирование данных, практическая реализация и развёртывание проекта».

Слайд 3 — Актуальность «Актуальность работы обусловлена тем, что рынок коллекционных товаров — винил, фигурки, монеты, ретро-игры — стремительно уходит в онлайн. При этом готовые шаблонные решения не позволяют передать атмосферу бренда и обеспечить качественный интерфейс. Поэтому было решено разработать собственный магазин на современных технологиях».

Слайд 4 — План «Доклад построен по следующей схеме: сначала теоретические основы, затем практическая реализация, наконец, развёртывание и итоги».

Слайд 5 — Разделитель «Теоретические основы» «Перейдём к первой главе — теоретическим основам разработки».

Слайд 6 — Объект и предмет «Объектом исследования стала деятельность магазина по продаже коллекционных товаров, а предметом — методы разработки клиентской части. Ключевое преимущество собственной площадки — прямые продажи без посредников, что повышает маржинальность и доверие покупателя».

Слайд 7 — Анализ конкурентов «Мы проанализировали существующие магазины. Их сильная сторона — сертификаты и бонусные системы. Но дизайн большинства сайтов перегружен баннерами и текстом, они медленно загружаются. Наше конкурентное преимущество — иммерсивный дизайн, высокая скорость React и чистый интерфейс без визуального шума».

Слайд 8 — Технологический стек «Для реализации мы отказались от тяжёлых CMS в пользу собственной разработки. Стек: Vite для сборки, React 18 для интерфейса, React Router для навигации, Context API для управления состоянием корзины и авторизации, CSS3 для адаптивной вёрстки и локальный Mock API, имитирующий сервер с искусственной задержкой».

Слайд 9 — Структура данных «Данные о товарах хранятся в JSON-файле, который имитирует таблицу базы данных — более 40 позиций. Каждый товар имеет идентификатор, название, категорию, эпоху, цену, рейтинг и изображение. Связи реализованы через фильтрацию по категориям на уровне приложения».

Слайд 10 — Разделитель «Практическая реализация» «Перейдём ко второй главе — практической реализации. Вот как выглядит готовый продукт».

Слайд 11 — Живой магазин «Это скриншоты реального развёрнутого магазина. Слева главная страница с баннером и сеткой категорий, справа — каталог с панелью фильтров. Проект опубликован на GitHub Pages и доступен по постоянной ссылке».

Слайд 12 — Архитектура «Приложение построено на модульной архитектуре. В папке components — переиспользуемые компоненты, в context — корзина и авторизация, в pages — страницы приложения, в services — слой работы с данными. Это обеспечивает единый источник истины для всего состояния».

Слайд 13 — Корзина и валидация «Корзина построена на localStorage и Context API: она сохраняется даже после перезагрузки. Слева видно наполненную корзину с изменением количества на лету, справа — форму оформления заказа со строгой валидацией имени, почты и телефона. Для телефона реализована автоматическая маска формата „+7 (900) 000-00-00“».

Слайд 14 — Админ-панель «Для администратора реализована панель управления базой. Здесь можно искать, добавлять, редактировать и удалять товары через таблицу. Данные администратора сохраняются в браузере».

Слайд 15 — Деплой «Проект развёрнут на бесплатном хостинге GitHub Pages. С помощью GitHub Actions настроена автопубликация: при каждом git push сайт автоматически пересобирается и обновляется. Также реализована адаптивная вёрстка по принципу mobile-first».

Слайд 16 — Заключение «Таким образом, цель курсовой работы достигнута. Создан готовый к внедрению интернет-магазин с уникальным дизайном, автоматизацией заказов и развёртыванием. В дальнейшем проект можно расширить, подключив реальный бэкенд на Node.js или PHP и модуль онлайн-оплаты. Доклад окончен, спасибо за внимание! Готов ответить на ваши вопросы».
